# Audio files to add

Place your six short MP3 clips here, using these exact lowercase names:

- `birds.mp3`
- `ball.mp3`
- `cat.mp3`
- `dog.mp3`
- `mom.mp3`
- `dad.mp3`

This folder documents the required layout; the MP3 files are not included. For SPIFFS flashing, point your uploader configuration at this `data` directory (or copy these six MP3s into the uploader's configured `data` directory). Upload the filesystem image to each ESP32 separately. Both boards need their own copy of all six files.
